# 机器人建图平台

这是一个纯 Python、无第三方运行依赖的二维建图原型。当前接入二维激光扫描和二维里程计位姿，数据模型保留 `sensor_type`、`sensor_id` 和每帧元数据，后续可在同一套运行、事件和地图版本结构中接入 IMU、轮速计或视觉特征。

## 运行演示

```bash
python -m robot_mapping.cli demo ./robot_map_project
```

演示会生成两个人工场景：

- `true_loop`：带累积里程计偏差的闭合矩形路径。候选闭环由闭环前后各多帧扫描交叉验证，接受后执行位姿图修正。
- `similar_corridors`：两段局部外观接近但细节不同的走廊。系统不会因为单帧相似就折叠地图，而是要求多组相邻观察推出一致的相对位姿；该候选被拒绝。
- `competing_corridors`：两条外观几乎相同但连通关系不同的走廊，对同一重访形成两个互相冲突的闭环解释。两个解释分别作为独立假设保留，各自生成试用地图并持续接收后续观测；错误假设被观测排除后可查看排除依据、重开再比较，最终选定正确假设。

输出的 `DEMO_REPORT.md` 汇总操作差异，`map_versions/` 保存每个阶段的 PGM 栅格地图和位姿快照。真闭环场景还会依次生成原始漂移、接受修正、撤回修正和重新接受修正的地图版本。

## 工程数据

- `runs/<run>/scans.jsonl`：原始二维扫描，只追加，不被闭环改写。
- `runs/<run>/poses.jsonl`：原始里程计位姿，只追加。
- `events.jsonl`：闭环提议、接受、拒绝、撤回和地图版本事件。
- `map_versions/<version>/map.json`：构建该地图时使用的修正后位姿和闭环清单。
- `map_versions/<version>/map.pgm`：可直接查看的二维占据栅格地图。

## 闭环判定

粗筛使用可旋转的范围形状，解决回到原处时朝向变化的问题。真正的判定不只看一帧：系统取候选点前后扫描，对齐相邻观测，检查 ICP 误差、内点比例、多个相对位姿的平移散布和角度散布。只有多个观察相互一致时才允许接受；相似走廊可保留为拒绝记录，不会进入位姿图。

接受闭环会增加一条高权重位姿图约束并重新优化位姿，原始扫描仍保留在原文件中。撤回闭环不会删除历史，只会新增一条 `withdrawn` 事件；重新构建地图会生成新版本，旧版本仍可追溯。

## 竞争假设与局部修正

互相冲突的闭环（同一重访对应到不同锚点）不再逐条接受或撤回，而是组成独立的假设方案：

- 每个假设保留自己的闭环成员、连续后续观测证据和试用地图；试用地图只用于比较，不会改写公共地图。
- `advance_observations` 按闭环预测的对应位置喂入新扫描，用对称 Chamfer 误差判断支持或矛盾；连续矛盾且支持率不足时排除该假设，排除事件记录具体观测和误差。
- 被排除的假设可用 `reopen_hypothesis` 回到排除前状态重新比较；`exclusion_basis` 给出排除依据和对应的试用地图版本。
- `select_hypothesis` 才会接受该组闭环并生成选定地图；位姿图修正只作用于闭环附近的局部轨迹窗口，远处未受影响区域保持原里程计位姿。
- 撤回已接受的假设时，依赖该组闭环的局部修正一致回到原始轨迹；原始扫描和里程计始终只追加保存。

事件类型新增 `hypothesis`、`hypothesis_excluded`、`hypothesis_reopened`、`hypothesis_selected`、`hypothesis_withdrawn`，均写入 `events.jsonl`。
